## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/moh1tt/<repo-name>.git
cd <repo-name>

# Install dependencies
npm install

# Start the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
